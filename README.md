# Ассистент кондитера (Telegram Mini App)

Мобильное веб-приложение внутри Telegram (и в обычном браузере) для кондитера: техкарты тортов, мгновенный пересчёт себестоимости под любой диаметр, склад продуктов, планировщик закупок и калькуляторы форм и КБЖУ.

База данных при первом запуске пустая — вы заполняете свой склад продуктов и рецепты сами, и все данные автоматически синхронизируются между телефоном и компьютером через Neon PostgreSQL.

## Основные возможности

- **Мои торты (Техкарты):** динамические слои (бисквит, крем, начинка, пропитка и т.д.), быстрое создание продукта прямо из техкарты, переключатель диаметра `10–26 см` с формулой `(d / base_d)²`, расчёт себестоимости, цены продажи, чистой прибыли, цены за 1 кг и за 1 порцию, автоматическая сводка по всему торту.
- **Склад и цены:** ввод цены сразу за 1 кг или за упаковку (например, `180 г за 95 грн` → авторасчёт цены за кг), необязательные поля КБЖУ. При изменении цены продукта все техкарты пересчитываются автоматически.
- **Закупка:** выбор нескольких тортов с нужными диаметрами и количеством, единый список покупок с суммой закупки, удобные чекбоксы для магазина, копирование и отправка в Telegram.
- **Калькуляторы:** быстрый расчёт себестоимости без сохранения в базу, пересчёт рецепта по форме (круг/квадрат/прямоугольник + высота), по весу или по кратности, расчёт КБЖУ на 100 г и на порцию.
- **Telegram Mini App SDK:** автоматическое разворачивание на весь экран (`ready()` + `expand()`), адаптация под светлую/тёмную тему Telegram, тактильный отклик (`HapticFeedback`) и поддержка кнопки «Назад».

## 1. Настройка базы данных Neon PostgreSQL и миграции

1. Зарегистрируйтесь или войдите на [console.neon.tech](https://console.neon.tech) и создайте новый проект (например, `pastry-assistant`).
2. Откройте вкладку **Dashboard → Connection Details**, выберите **Pooled connection** и скопируйте строку подключения `postgresql://...`.
3. Создайте файл `.env` в корне проекта на основе `.env.example`:

```bash
cp .env.example .env
```

Вставьте вашу строку подключения в `.env`:

```env
DATABASE_URL="postgresql://neondb_owner:ПАРОЛЬ@ep-xxxx-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require"
```

4. Установите зависимости и примените SQL-миграцию к базе Neon:

```bash
npm install
npm run db:migrate
```

*(Альтернативно можно синхронизировать схему напрямую командой `npm run db:push` или выполнить SQL-файл [`drizzle/0000_init.sql`](drizzle/0000_init.sql) в **SQL Editor** консоли Neon.)*

Таблицы создадутся пустыми — без предзаполненных данных.

## 2. Локальный запуск

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

> Если `DATABASE_URL` ещё не указан, приложение запустится в локальном режиме (данные сохраняются в `.local-data/pastry-db.json`). Для синхронизации между телефоном и компьютером подключите Neon PostgreSQL.

---

## 3. Деплой на Vercel

1. Загрузите репозиторий проекта на GitHub.
2. Зайдите на [vercel.com](https://vercel.com) → **Add New… → Project** и выберите ваш репозиторий.
3. В разделе **Environment Variables** добавьте переменную:
   - **Key:** `DATABASE_URL`
   - **Value:** ваша строка подключения Neon (Pooled connection).
4. Нажмите **Deploy**. После завершения деплоя скопируйте итоговый HTTPS-адрес приложения, например:
   `https://pastry-assistant.vercel.app`

## 4. Привязка в `@BotFather` как Telegram Mini App

1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Создайте нового бота командой `/newbot` (или используйте существующего):
   - введите отображаемое имя, например `Ассистент кондитера`;
   - введите username, заканчивающийся на `bot`, например `my_pastry_helper_bot`.
3. Привяжите Mini App к кнопке меню бота (самый удобный способ для ежедневного открытия):
   - отправьте команду `/setmenubutton`;
   - выберите вашего бота;
   - отправьте HTTPS-ссылку на Vercel: `https://pastry-assistant.vercel.app`;
   - введите текст кнопки, например `Открыть ассистент`.
4. *(Необязательно)* Также можно создать прямую ссылку вида `t.me/ваш_бот/app`:
   - отправьте команду `/newapp` в `@BotFather`;
   - выберите бота, укажите название, описание, иконку (640×360 px) и вставьте ту же HTTPS-ссылку Vercel.
5. Откройте диалог с вашим ботом в Telegram на телефоне или компьютере и нажмите кнопку меню — приложение откроется на весь экран.
